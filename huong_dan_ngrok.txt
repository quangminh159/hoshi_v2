========== HƯỚNG DẪN CHẠY HOSHI + NGROK ==========

Cần 2 terminal, cùng thư mục: C:\hoshi_v2

----------------------------------------
BƯỚC 1 — CHẠY SERVER (Daphne)
----------------------------------------
cd C:\hoshi_v2
.\venv\Scripts\python.exe -m daphne -b 0.0.0.0 -p 8000 hoshi.asgi:application

Thấy "Listening on ... 8000" là OK.
Giữ terminal này chạy (đừng tắt).

Lưu ý:
- Dùng đúng .\venv\Scripts\python.exe
- Muốn chat / gọi thoại thì dùng Daphne, không dùng manage.py runserver

----------------------------------------
BƯỚC 2 — MỞ NGROK (in link ra Terminal)
----------------------------------------
Mở terminal thứ 2:

cd C:\hoshi_v2
.\start_ngrok.ps1

Script sẽ in rõ link dạng:
https://xxxx.ngrok-free.app
và tự copy vào clipboard.

Hoặc xem thêm trên PC: http://127.0.0.1:4040

Giữ ngrok chạy trong lúc test (cửa sổ ngrok có thể bị minimize).

----------------------------------------
BƯỚC 3 — MỞ TRÊN ĐIỆN THOẠI
----------------------------------------
1. Dán URL https://....ngrok-free.app vào trình duyệt điện thoại
2. Lần đầu ngrok hiện cảnh báo → bấm "Visit Site"
3. Đăng nhập Moora và test (dùng được cả 4G)

----------------------------------------
TẮT / BẬT LẠI
----------------------------------------
Tắt server (tìm PID cổng 8000):
netstat -ano | findstr ":8000"
Stop-Process -Id <PID> -Force

Tắt ngrok: Ctrl+C ở terminal ngrok

Mỗi lần tắt rồi bật lại ngrok → URL có thể đổi → copy URL mới

----------------------------------------
LỖI THƯỜNG GẶP
----------------------------------------
- Port 8000 bị chiếm:
  netstat -ano | findstr ":8000"
  Stop-Process -Id <PID> -Force
  rồi chạy lại Daphne

- Điện thoại không vào được:
  kiểm tra cả 2 terminal còn chạy, URL đúng https://

- Chat / gọi không realtime:
  phải dùng Daphne, không dùng runserver

----------------------------------------
TEST GỌI ĐIỆN THOẠI ↔ MÁY TÍNH (ngrok)
----------------------------------------
Lỗi hay gặp: "Không kết nối được cuộc gọi (mạng/ICE)".

Vì sao: ngrok chỉ chuyển web/chat. Âm thanh/video WebRTC đi P2P hoặc TURN.
- Cùng WiFi: thường được (P2P)
- ĐT 4G ↔ PC WiFi: BẮT BUỘC TURN thật (Metered free API)

→ Xem chi tiết: huong_dan_turn.txt

Cách A — test nhanh (cùng WiFi):
1. ĐT và PC cùng một WiFi
2. Cả hai mở CÙNG link https ngrok (PC đừng dùng localhost)
3. Hard refresh, cho phép micro → gọi thoại

Cách B — khác mạng / 4G (TURN tự host, không dùng Metered):
→ Xem huong_dan_turn.txt
1. .env: TURN_HOST + TURN_EXTERNAL_IP = IP public máy bạn, TURN_USERNAME/CREDENTIAL
2. docker compose --profile turn up -d
3. Mở firewall Windows (3478, 49160-49200) — chạy PowerShell Admin nếu cần
4. Restart Daphne, hard refresh, gọi thử

KHÔNG cần tạo app trên metered.live.
KHÔNG đặt WEBRTC_PREFER_RELAY=True trừ khi TURN đã chắc chắn chạy.

Restart Daphne:
.\venv\Scripts\python.exe -m daphne -b 0.0.0.0 -p 8000 hoshi.asgi:application

----------------------------------------
GỌI THOẠI / VIDEO (kiểu Facebook / Instagram)
----------------------------------------
Gọi ngay trong app (overlay full màn), không mở cửa sổ riêng.
- Cuộc gọi đến: hiện full màn → Trả lời / Từ chối
- Đang gọi: có thể thu nhỏ thành bóng nổi để lướt feed/chat
- Nhận cuộc gọi cả khi đang ở trang khác (qua inbox WS)

Restart Daphne sau khi đổi .env:
.\venv\Scripts\python.exe -m daphne -b 0.0.0.0 -p 8000 hoshi.asgi:application
